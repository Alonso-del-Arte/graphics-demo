# Graphics Demo

WORK IN PROGRESS

For a Medium article to demonstrate the basics of GUI programming from the Java 
perspective. I'll be sure to put the link here.

The idea is that this will be a very simple program that draws a bunch of trees 
near a shore and allows the user to move trees around. I've decided the default 
number of trees will be 31, and the maximum number of trees will be 127.

This project is for Java 21, with the test dependencies being TestNG 6.14.3 and 
TestFrame 1.01.

Presently you're looking at the main branch. On February 1, 2026, I decided to 
make a quick and dirty branch in which I would suspend my usual methodology to 
get this demo out quickly and not hold up the Medium article much longer. But 
I'm finding that trying to do this quick and dirty is actually kind of slow for 
me.

Also, and this is kind of arbitrary, I downgraded the quick and dirty branch to 
Java 8.
